# Star Math Voyage

A browser math game for 4th graders. Fly a rocket to seven planets and blast the
asteroid carrying the right answer to rescue the alien who lives there.

Play it: https://abezuglov.github.io/star-math-voyage/

- **Planets:** addition and subtraction, multiplication, division with remainders,
  fractions, word problems and rounding, perimeter and area, mixed numbers and decimals.
- **Adaptive difficulty:** each planet has five challenge levels. Correct answers
  on the first try raise the level; a missed question lowers it, and that kind of
  question comes back later.
- **Feedback:** a miss gets a hint and a second try, then a worked solution.
- **Rewards:** stardust to spend in the hangar shop, 12 badges, and an endless
  Asteroid Storm mode that opens after three rescues.
- **Saves:** progress is stored in the browser. A save code on the map screen
  carries it to another device. Entering `UNLOCK-ALL` there opens every planet.
- **No accounts, no tracking.**

## Run it

Open `index.html` in a browser. It is a single file with no build step.

## Deploy

Served by GitHub Pages from the root of the `main` branch.
