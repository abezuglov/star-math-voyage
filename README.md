# Star Math Voyage

A browser math game for 4th graders. Fly a rocket to five planets and blast the
asteroid carrying the right answer to rescue the alien who lives there.

- **Planets:** addition and subtraction, multiplication, division with remainders,
  fractions, word problems and rounding.
- **Adaptive difficulty:** each planet has five challenge levels. Correct answers
  on the first try raise the level; a missed question lowers it.
- **Feedback:** a miss gets a hint and a second try, then a worked solution.
- **No accounts, no tracking:** progress is saved only in the browser.

## Run it

Open `index.html` in a browser. It is a single file with no build step.

## Deploy

Served by GitHub Pages from the root of the `main` branch.
